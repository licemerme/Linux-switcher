# Switcher - Программа переключения раскладки клавиатуры

Программа аналогична Punto Switcher для Linux KDE, которая отслеживает ввод клавиатуры и переключает раскладку между русской и английской раскладками.

## Особенности

- Автоматическое определение ввода русских слов на английской раскладке
- Переключение раскладки и исправление введённых слов
- Минимальные настройки
- Сворачивание в системный трей
- Поддержка автозапуска
- Использование системных словарей

## Установка

1. Установите зависимости:
```bash
pip install PyQt5
```

2. Запустите программу:
```bash
python switcher_system.py
```

## Использование

- Программа запускается в системном трее
- При вводе слова на неправильной раскладке программа автоматически исправляет его и переключает раскладку
- Используйте кнопку "Переключить раскладку" для ручного переключения
- Включите "Автозапуск" для автоматического запуска при старте системы

## Требования

- Linux с KDE или X11
- Python 3
- PyQt5
- setxkbmap (часть x11-xkb-utils)

## Работа программы

Программа работает следующим образом:
1. При вводе текста проверяет, является ли слово русским, но написанным на английской раскладке
2. Если да - исправляет слово на правильное написание и переключает раскладку на русскую
3. Использует системные словари для определения соответствия

## Системные словари

Программа использует системные словари, доступные в Fedora:
- `/usr/share/dict/russian` (русский словарь)
- `/usr/share/dict/american` (английский словарь)
